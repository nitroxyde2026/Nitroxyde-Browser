Installer sur Windows.

Cinq étapes, environ cinq minutes. Les pastilles jaunes numérotées sur les images indiquent où cliquer.

Télécharge le fichier

Clique sur « Télécharger pour Windows ». Ton navigateur peut afficher une alerte : un fichier peu téléchargé n’est pas considéré comme sûr d’office.

  • Edge : clique sur les trois points … à côté du fichier, puis « Conserver », puis « Afficher plus » et « Conserver quand même ».
  • Chrome : clique sur « Conserver » (ou « Télécharger quand même »).
  • Firefox : ouvre le menu du téléchargement et choisis « Autoriser le téléchargement ».

Ouvre le fichier

Va dans ton dossier Téléchargements et double-clique sur Nitroxyde-Navigation-Setup-0.8.0.exe. Une fenêtre bleue « Windows a protégé votre ordinateur » apparaît : c’est SmartScreen, le filtre de Windows.

Ne clique pas sur « Ne pas exécuter ». Clique sur le texte souligné « Informations complémentaires ».

Clique sur « Exécuter quand même »

Un bouton supplémentaire apparaît. Windows indique « Éditeur inconnu » parce que Nitroxyde n’est pas signé : c’est ce qui déclenche l’avertissement, pas un problème détecté dans le fichier.

Le bouton n’apparaît pas ? Va voir « Fichier bloqué » dans l’aide.

Installe Nitroxyde

L’assistant d’installation s’ouvre, en français ou en anglais selon ton système.

  • « Uniquement pour moi » (en anglais : Only for me) : aucun droit administrateur n’est nécessaire.
  • Clique sur « Suivant » (Next), laisse le dossier proposé, puis « Installer » (Install).
  • Termine avec « Terminer » (Finish) : Nitroxyde se lance.

Choisis ton mode

Au premier lancement, un écran te propose Basique (tout est actif) ou Gaming (ressources réservées au jeu). Tu pourras changer à tout moment depuis le menu ☰ puis « Mode ».

Voir les premiers pas

Pourquoi cet avertissement ?

Windows SmartScreen vérifie que l’éditeur d’un programme est connu et que le programme a déjà été téléchargé par beaucoup de monde. Nitroxyde est un nouveau projet gratuit, sans certificat de signature (payant) : Windows ne le connaît donc pas encore. L’avertissement ne prouve pas qu’un fichier est dangereux, mais il ne prouve pas non plus qu’il est sûr. Par prudence, télécharge uniquement depuis nitroxyde.fr et vérifie l’empreinte.

Vérifie ton fichier.

L’empreinte SHA-256 est comme une carte d’identité du fichier : si tu obtiens la même chez toi, le fichier n’a pas été modifié.
