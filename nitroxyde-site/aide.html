On t’aide à installer.

Cette page répond aux problèmes d’installation les plus courants, étape par étape. Prends ton temps : chaque réponse est indépendante.

À savoir avant de continuer. Les manipulations ci-dessous consistent à autoriser un programme que Windows ne connaît pas. Ne les applique qu’à un fichier téléchargé depuis nitroxyde.fr, dont tu as, si possible, vérifié l’empreinte.

Mon navigateur bloque le téléchargement

Edge, Chrome et Firefox préviennent quand un fichier exécutable est rarement téléchargé. Le fichier n’est pas supprimé : il attend ton accord.

  1. Edge : dans la liste des téléchargements, clique sur les trois points … à côté du fichier, puis « Conserver ». Si un second message apparaît, clique sur « Afficher plus » puis « Conserver quand même ».
  2. Chrome : ouvre la liste des téléchargements (icône flèche vers le bas), puis clique sur « Conserver » ou « Télécharger quand même ».
  3. Firefox : ouvre le panneau des téléchargements, clique sur le fichier signalé puis sur « Autoriser le téléchargement ».

« Windows a protégé votre ordinateur »

C’est l’avertissement Microsoft Defender SmartScreen. Il apparaît pour tout programme dont l’éditeur est inconnu.

  1. Dans la fenêtre bleue, clique sur le texte souligné « Informations complémentaires ».
  2. Un bouton « Exécuter quand même » apparaît en bas de la fenêtre. Clique dessus.
  3. L’installateur se lance. Si Windows demande « Voulez-vous autoriser cette application à apporter des modifications ? », clique sur « Oui ».

Le bouton « Exécuter quand même » n’apparaît pas

Windows marque parfois les fichiers téléchargés comme « bloqués ». On peut lever ce blocage soi-même :

  1. Fais un clic droit sur Nitroxyde-Browser-Setup-0.10.3.exe, puis « Propriétés ».
  2. Dans l’onglet « Général », tout en bas, repère la case « Débloquer » (section « Sécurité »). Coche-la.
  3. Clique sur « Appliquer » puis « OK », et relance le fichier.

Si la case « Débloquer » n’existe pas, le fichier n’est pas bloqué : passe à la section suivante.

Mon antivirus ou Microsoft Defender a supprimé le fichier

Les programmes récents et non signés déclenchent parfois de fausses alertes. Avant de continuer, vérifie l’empreinte du fichier (voir plus bas) si tu l’as encore.

  1. Ouvre « Sécurité Windows », puis « Protection contre les virus et menaces ».
  2. Clique sur « Historique de protection ».
  3. Repère l’élément correspondant à Nitroxyde, ouvre « Actions » puis choisis « Restaurer » ou « Autoriser sur l’appareil ».
  4. Retélécharge le fichier si besoin et relance l’installation.

Avec un antivirus tiers (Avast, Kaspersky, Norton…), cherche la « quarantaine » dans ses réglages et restaure le fichier depuis cet endroit.

« Une stratégie de contrôle d’application a bloqué ce fichier »

Ce message indique que Smart App Control est activé. Cette protection de Windows 11 refuse tout programme non signé et ne propose pas de bouton pour passer outre. Pour installer Nitroxyde, il faut la désactiver :

  1. Ouvre « Sécurité Windows », puis « Contrôle des applications et du navigateur ».
  2. Clique sur « Paramètres Smart App Control ».
  3. Choisis « Désactivé ».

Attention : selon ta version de Windows, Smart App Control ne peut pas être réactivé ensuite sans réinitialiser Windows. Ne le désactive que si tu es à l’aise avec ce choix.

Vérifier que le fichier n’a pas été modifié

Compare l’empreinte SHA-256 de ton fichier avec celle publiée sur la page de téléchargement. Si elles sont identiques, c’est le bon fichier.

Sous Windows : ouvre le dossier Téléchargements, fais un clic droit sur une zone vide en maintenant la touche Maj, puis « Ouvrir dans le terminal » (ou « Ouvrir la fenêtre PowerShell ici »). Tape :

Get-FileHash .\Nitroxyde-Browser-Setup-0.10.3.exe -Algorithm SHA256

Compare la valeur de la ligne « Hash » avec celle de la page. Les majuscules et minuscules n’ont pas d’importance.

Sous macOS : dans le Terminal, tape shasum -a 256 suivi d’un espace, glisse le fichier dans la fenêtre, puis appuie sur Entrée. Sous Linux : sha256sum suivi du nom du fichier.

macOS (quand une version sera disponible)

  1. Ouvre le fichier .dmg et glisse Nitroxyde Browser dans le dossier Applications.
  2. Au premier lancement, macOS peut dire que le développeur ne peut pas être vérifié. Dans « Réglages Système », ouvre « Confidentialité et sécurité », descends jusqu’au message sur Nitroxyde Browser et clique sur « Ouvrir quand même ».
  3. Sur les versions plus anciennes de macOS, un clic droit sur l’application puis « Ouvrir » suffit.
  4. Si macOS annonce que l’application est « endommagée », ouvre le Terminal et tape la commande ci-dessous, puis relance l’application :
xattr -cr "/Applications/Nitroxyde Browser.app"

Linux (quand une version sera disponible)

  1. Rends le fichier exécutable : clic droit, « Propriétés », « Permissions », puis « Autoriser l’exécution », ou dans un terminal :
chmod +x Nitroxyde-Browser-0.10.3.AppImage
  1. Lance-le par un double-clic, ou avec ./ suivi du nom du fichier.
  2. Si rien ne se passe sur Ubuntu, installe la bibliothèque manquante avec sudo apt install libfuse2.
  3. Si un message parle d’un « sandbox » qui n’est pas configuré, lance-le une fois avec l’option --no-sandbox (à la fin de la commande).

Désinstaller Nitroxyde

  1. Ouvre « Paramètres » de Windows, puis « Applications » et « Applications installées ».
  2. Repère « Nitroxyde Browser », clique sur les trois points puis « Désinstaller ».
  3. Pour effacer aussi tes données (historique, favoris, réglages), supprime le dossier %APPDATA%\Nitroxyde Browser : colle cette adresse dans la barre de l’Explorateur de fichiers.

Questions fréquentes

Nitroxyde est-il gratuit ?

Oui, entièrement. Il n’y a ni compte à créer ni abonnement. Seuls certains services externes que tu choisis d’utiliser, comme les crédits ChatGPT ou Claude pour l’aperçu IA, peuvent être payants chez leur éditeur. Groq et Gemini proposent une clé gratuite.

Pourquoi Windows affiche-t-il un avertissement ?

Windows SmartScreen met en garde contre tout programme dont l’éditeur n’est pas reconnu. Signer un programme avec un certificat reconnu est payant, et Nitroxyde n’est pas encore signé. L’avertissement ne signifie pas que le fichier est dangereux, mais que Windows ne le connaît pas encore. Le guide explique comment continuer, et comment vérifier le fichier.

Voir la marche à suivre

Est-ce sûr ?

Nitroxyde repose sur Chromium, le moteur de Chrome et d’Edge. Il ne contient aucune publicité et n’envoie aucune donnée de navigation à Nitroxyde. Télécharge-le uniquement depuis nitroxyde.fr et compare l’empreinte du fichier (SHA-256) avec celle affichée sur la page de téléchargement pour t’assurer qu’il n’a pas été modifié.

Comment vérifier l’empreinte

Mon antivirus bloque le fichier, que faire ?

Les logiciels récents et peu connus déclenchent parfois de fausses alertes. Si tu as vérifié l’empreinte du fichier, tu peux le restaurer depuis l’historique de ton antivirus.

Voir la marche à suivre

Nitroxyde envoie-t-il des données sur moi ?

Non : pas de compte, pas de télémétrie, pas de statistiques d’usage. Historique, favoris et réglages restent sur ton ordinateur. Certaines fonctions contactent des services externes quand tu les utilises (actualités, météo, IA, listes du bloqueur de pubs) : tout est détaillé dans la page confidentialité.

Puis-je installer des extensions Chrome ?

En partie. Nitroxyde peut charger des extensions décompressées, mais seule une partie de l’interface des extensions Chrome est prise en charge, et il n’y a pas d’accès au Chrome Web Store. Le bloqueur de publicités est déjà intégré.

Existe-t-il une version pour téléphone ?

Pas pour l’instant. Nitroxyde fonctionne sur ordinateur. Tu peux retrouver tes favoris sur un autre PC grâce à la synchronisation par dossier (OneDrive, Google Drive, Dropbox).

Comment mettre à jour Nitroxyde ?

Nitroxyde te prévient quand une nouvelle version est disponible. Télécharge alors le nouvel installateur sur cette page et lance-le : tes réglages, favoris et historique sont conservés.

Où sont enregistrées mes données ?

Dans le dossier de ton profil Windows, sous %APPDATA%\Nitroxyde Browser. Supprime ce dossier si tu veux effacer toutes les données après avoir désinstallé le navigateur.

Toujours bloqué ? Les moyens de nous contacter sont indiqués dans les mentions légales. Indique ta version de Windows et le message exact affiché.
